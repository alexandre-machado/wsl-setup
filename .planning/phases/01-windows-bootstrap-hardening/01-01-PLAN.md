<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user input → PowerShell bootstrap | Untrusted mode/confirmation input controls destructive branch eligibility |
| PowerShell bootstrap → WSL CLI | Host script invokes privileged WSL install/unregister operations |
| PowerShell bootstrap → bash handoff | User identity strings cross shell boundary into `bash -lc` command |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | T (Tampering) | `wsl-setup.ps1` replace-existing branch | mitigate | Compute eligibility from preflight state and block destructive mode when target distro is absent before branch execution. |
| T-01-02 | E (Elevation of privilege) | `wsl --unregister` call path | mitigate | Keep unregister behind explicit Y confirmation and keep decline path non-destructive. |
| T-01-03 | I (Information disclosure) | Preflight summary output | accept | Summary shows only local install/distro names and no secrets; keep output scope limited to WSL state. |
| T-01-04 | T (Command injection) | `Invoke-BashHandoff` env interpolation | mitigate | Preserve single-quoted env export style and avoid introducing unquoted interpolation in `bash -lc` handoff string. |
</threat_model>
